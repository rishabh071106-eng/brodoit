02

The three sorting questions

Do you have labeled data?
Known answers attached to examples → Supervised. No answers → Unsupervised.
Is it sequential with decisions & rewards?
Actions change the world and get scored over time → Reinforcement Learning.
Is the data huge and unstructured?
Images, free text, audio, video at scale → Deep Learning (often inside another family).

A secret Byte shares early: deep learning is not a rival family — it's heavy machinery. A CNN classifying X-rays is still supervised learning; it just uses a neural network instead of a decision tree. The map tells you the family; scale and data type tell you whether the tool should be deep.

Chapter takeaway

Never start from the algorithm. Start from three facts about your problem — labels, rewards, and data shape — and the family picks itself.

03

Inside the machines

“I add up all the clues — income ×2, missed payments ×−5 — and pass the total through an S-shaped gate. Out comes: 0.83 chance of repaying.”
How it works inside

Each feature gets a learned weight. Multiply, sum, then apply the sigmoid function σ(z)=1/(1+e⁻ᶻ), which bends any number into (0,1). Training nudges weights to make predicted probabilities match the labels (maximizing likelihood via gradient descent).

Reach for it when: you need a fast, explainable baseline with calibrated probabilities (credit risk, medical screening). It draws a straight boundary — if the truth is curvy, move on.

“I don't just separate the classes — I build the widest road between them, so new points landing near the edge still fall on the right side.”
How it works inside

Finds the boundary that maximizes the margin — the distance to the nearest points of each class (the support vectors; only they matter). The kernel trick (e.g. RBF) implicitly lifts data into a higher dimension where a curvy boundary becomes a flat one.

Reach for it when: medium-sized data, clear separation matters, you don't need probability outputs (choose 2A.2 = “boundary”). Great for text with clean features; slows down on huge datasets.

“Price ≈ 40×area + 8×bedrooms − 3×age. I find the line whose total squared miss is smallest. Ridge fines me for big weights; Lasso fines me until useless weights hit exactly zero.”
How it works inside

Least squares: pick weights minimizing Σ(actual−predicted)². Ridge adds λΣw² (shrinks weights smoothly), Lasso adds λΣ|w| (zeroes out weak features — free feature selection). Elastic Net blends both.

Reach for it when: the relationship looks roughly linear (2A.3 = linear), you want interpretability, or you have few data points. It's the baseline every regression should beat.

“I ask 500 slightly-different experts. Each saw a random slice of the data and is a bit wrong in their own way — but their average is scarily right.”
How it works inside

Each tree trains on a bootstrap sample (random rows) and considers only a random subset of features at each split — forcing the trees to disagree. Classification: majority vote. Regression: average. Randomness + averaging cancels individual overfitting.

Reach for it when: tabular data with messy, non-linear patterns (2A.3 = non-linear). Nearly tuning-free, handles mixed features, gives feature importance. The workhorse of practical ML.

“Tree 1 guesses. I look at what it got wrong, and train Tree 2 only on those errors. Then Tree 3 on what's still wrong. A relay team of error-fixers.”
How it works inside

Gradient boosting: each new tree predicts the residual errors of the ensemble so far, taking a gradient-descent step in function space. XGBoost adds clever regularization, missing-value handling, and speed. Kaggle's long-reigning king of tabular data.

Reach for it when: you need maximum accuracy on structured/tabular data and are willing to tune. Try Random Forest first; switch to XGBoost when you're chasing the last few points of accuracy.

“When the price curve bends and twists, I either bend space itself (SVR-RBF) or stack little neurons until the curve fits (MLP).”
How it works inside

SVR (RBF) is SVM's regression cousin: fit a tube around the data, ignore errors inside the tube, use the RBF kernel for curves. MLP (multi-layer perceptron) stacks layers of weighted sums + activations; backpropagation adjusts every weight against the error. It can approximate any continuous function — given enough data.

Reach for it when: strong non-linearity, enough data, and tree ensembles underperform — or as the bridge into deep learning for tabular problems.

04

Supervised works best when…

You have labeled historical data — the answer key exists.
There's a clear target to predict (a category or a number).
The future resembles the past — patterns are stable enough to learn.
You can measure success: accuracy, error, precision/recall.
Chapter takeaway

Category → classification. Number → regression. Start simple (Logistic / Linear), earn complexity (Forests, XGBoost, Neural Nets) only when the data proves it's needed.

03

Inside the machines

“I throw 3 tent poles into the crowd. Everyone walks to their nearest pole. I move each pole to the middle of its crowd. We repeat until nobody switches tents.”
How it works inside

1) Place K centroids randomly. 2) Assign each point to nearest centroid. 3) Update each centroid to the mean of its points. 4) Repeat until stable. Minimizes within-cluster distance. You choose K (use the elbow method).

Reach for it when: numerical data, roughly round clusters, you have a K in mind. Fast and scalable — the default first clustering attempt.

“I walk from point to point. If enough neighbors live within ε steps, we're the same village — however weird the village's shape. Hermits in the wilderness? Marked as noise.”
How it works inside

A point with ≥ minPts neighbors within radius ε is a core point; clusters grow by chaining core points. Finds arbitrary-shaped clusters (moons, spirals) and labels sparse points as outliers — clustering and anomaly detection in one move.

Reach for it when: unknown cluster count, weird shapes, or noisy data with outliers. Struggles when densities vary wildly.

“Your 100 columns mostly repeat each other. I find the few master directions — 'overall spend', 'visit rhythm' — that carry 95% of the story, and archive the remaining noise.”
How it works inside

Computes the eigenvectors of the covariance matrix — orthogonal axes ranked by how much variance they capture (principal components). Keep the top few, project data onto them: fewer columns, most of the information. Linear, fast, deterministic.

Reach for it when: too many numerical features, multicollinearity, speed-up needed before another model, or 2-D visualization (then compare with t-SNE/UMAP, which preserve local structure non-linearly).

“I slice the data with random cuts, like a game of guess-who. Normal points take many cuts to corner. The 3 AM gift-card buyer? Isolated in two cuts. Suspicious.”
How it works inside

Builds random trees that split on random features at random thresholds. The average path length to isolate a point becomes its score — outliers isolate in very few splits. No distance metric, so it scales to high dimensions beautifully.

Reach for it when: fraud/defect/intrusion detection on tabular data, especially high-dimensional. Cousins: One-Class SVM (draws a boundary around “normal”) and LOF (compares each point's local density to its neighbors').

“GMM says: this customer is 70% night-owl, 30% family-shopper — clusters overlap, and that's fine. Hierarchical says: let me show you the whole family tree, from every-point-alone to one-big-tribe.”
How it works inside

GMM models data as overlapping Gaussian blobs; the EM algorithm alternates “which blob likely owns each point?” with re-fitting blob shapes. Gives soft membership probabilities. Hierarchical (agglomerative) repeatedly merges the two closest clusters, producing a dendrogram you can cut at any level — no fixed K required.

Reach for it when: clusters overlap (GMM) or you want to explore grouping at many granularities (hierarchical). Autoencoders — neural nets that squeeze data through a bottleneck — take over dimensionality reduction when patterns are non-linear and data is big.

04

Unsupervised works best when…

You have unlabeled data — no answer key exists (or labeling is too expensive).
The goal is discovery: segments, structure, compression, weirdness.
You'll validate findings with domain eyes — metrics are fuzzier here.
It can be step one: clusters and components often become features for a supervised model later.
Chapter takeaway

No labels? Ask what you want: groups → clustering, fewer columns → dimensionality reduction, relationships → association, weird points → anomaly detection.

03

Inside the machines

“A neuron is a tiny judge: it weighs its inputs, sums them, and fires through a bent gate (ReLU). Stack thousands. When the final answer is wrong, backpropagation walks the error backwards, telling every judge exactly how much it's to blame — and each shifts its weights a little. A million rounds later: intelligence.”
How it works inside

Forward pass: data flows through layers of weighted sums + activations. Loss measures the miss. Backward pass: the chain rule distributes gradients to every weight; the optimizer (SGD/Adam) nudges them downhill. Depth lets features build on features.

“I don't look at a photo pixel-by-pixel. I slide small pattern-detectors — edge-finders, curve-finders — across it. Wherever a detector lights up, I note it on a map. Deeper layers slide detectors over those maps: whisker-maps + ear-maps = cat.”
How it works inside

Convolution: a small learned filter (e.g. 3×3) slides over the image producing a feature map — same pattern detected anywhere (translation invariance, few parameters). Pooling shrinks maps, keeping strong signals. Stack: edges → textures → parts → objects. ResNet adds skip-connections so 100+ layers still train; EfficientNet scales width/depth/resolution in balance.

Variants: detection (YOLO draws boxes in one pass — real-time), segmentation (U-Net labels every pixel), generation (GANs: forger vs detective; Diffusion: sculpt images out of noise, step by step).

“In 'the bank of the river', how do I know 'bank' isn't about money? Because 'bank' attends to 'river'. In a transformer, every word asks every other word: 'how much do you matter to my meaning?' — all in parallel.”
How it works inside

Self-attention: each token emits a query, key and value vector; attention scores = how much each token should borrow meaning from every other. Multi-head attention runs many such conversations at once; stacking layers builds deep context. No recurrence → massively parallel → trainable on internet-scale text.

The family: BERT/RoBERTa read bidirectionally — best for classification, NER, QA. T5/BART are encoder-decoders — best for summarization and translation. GPT/LLaMA/Claude are decoder-only next-token predictors scaled to billions of parameters — chat, reasoning, code. Fine-tune or prompt; rarely train from scratch.

“I listen to audio like you read a sentence — one frame at a time, updating a little notebook of what I've heard. LSTM gave my notebook gates: what to write, what to erase, what to say aloud.”
How it works inside

A recurrent cell takes the current input + its own previous hidden state. LSTM adds input/forget/output gates so memory survives long sequences (fixing vanishing gradients). Still strong for streaming audio and time series, though Transformers now dominate offline speech (Whisper-style) and 1-D CNNs handle audio classification.

“A video is a flip-book. My 3D convolutions slide through height, width and time — so I see 'jumping', not just 'person'. SlowFast watches twice: slow stream for scene, fast stream for motion.”
How it works inside

3D CNNs extend filters into the time axis to learn motion features (action recognition). For tabular data at scale, TabNet uses sequential attention to pick which features to reason about per decision step; FT-Transformer treats each column as a token. Honest rule: on most tabular problems, gradient-boosted trees still win — benchmark before going deep.

04

Deep learning works best when…

Data is large in volume and high-dimensional.
Data is unstructured: images, text, audio, video, sequences.
You need state-of-the-art accuracy and can pay in compute/GPUs.
Features are too subtle to hand-engineer — let the network learn them.
Chapter takeaway

In deep learning, the data type picks the architecture: images → CNN, text → Transformer, audio → RNN/Transformer, video → 3D CNN, giant tabular → maybe TabNet (but race XGBoost first).

03

Inside the machines

“I see where I am (state). I choose a move (action). The world scores me (reward) and shifts (new state). My only goal: choose actions that maximize the total reward over the whole future — not just the next treat.”
How it works inside

Formalized as a Markov Decision Process. The discount factor γ makes near rewards worth more than far ones. The deepest tension is exploration vs exploitation: keep trying new moves (ε-greedy) or you'll never find the better path; keep using the best-known moves or you'll never cash in.

“I keep a giant table: 'in square B3, going LEFT is worth 42.' Every surprise updates the table. But an Atari screen has more states than atoms in the universe — so DQN swapped my table for a neural network that estimates the scores.”
How it works inside

The Bellman update: Q(s,a) ← Q(s,a) + α[r + γ·maxQ(s′,·) − Q(s,a)] — pull each estimate toward reward-plus-best-future. DQN approximates Q with a network and stabilizes it via experience replay (learn from shuffled past moments) and a frozen target network. Double DQN fixes overoptimism; Dueling DQN separates “how good is this state?” from “how much better is each action?”.

Reach for it when: action space is a discrete menu — game moves, routing choices, up/down decisions.

“Instead of scoring every move, I train my instincts directly: replay an episode, and make every action that led to victory a bit more likely (REINFORCE). My critic friend whispers 'that was better than expected' so I don't overreact to lucky wins (A2C).”
How it works inside

A policy network outputs action probabilities; gradients push up the probability of actions weighted by how good their outcomes were. Actor-critic pairs it with a value network (the critic) to reduce variance; A3C runs many actors in parallel environments.

“A robot elbow doesn't pick from a menu — it outputs 23.7 degrees of torque. And when I learn, I take small, clipped steps (PPO), because one wild policy update can un-learn a month of walking practice.”
How it works inside

PPO clips each policy update so the new behavior can't stray far from the old — simple, stable, the default choice (also used in RLHF for LLMs). SAC adds an entropy bonus: stay as random as possible while still winning → robust exploration. DDPG/TD3 learn a deterministic action function with a Q-critic; TD3 tames DDPG's overestimation with twin critics and delayed updates.

Reach for it when: robotics, control, driving, any continuous dial. Start with PPO or SAC.

04

RL works best when…

The problem is sequential — decisions now change options later.
There's a reward signal (or you can design one honestly).
You have a simulator or cheap trials — RL is data-hungry and failure-prone.
Examples: games, robotics, recommendations over time, resource scheduling, RLHF.
Chapter takeaway

Sequential + reward → RL. Then one question routes everything: discrete menu of actions → DQN family; continuous dials → PPO/SAC family.
